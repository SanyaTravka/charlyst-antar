# Уровневые хиты: бросок кости или среднее (design)

Дата: 2026-08-19

## Цель

При повышении уровня персонаж получает хиты одним из двух способов на выбор в модалке повышения уровня:
- **Бросок кости** — случайное значение d6/d8/d10/d12 (минимум 1)
- **Среднее кости** — `floor(d/2)+1`: 6→4, 8→5, 10→6, 12→7

Мод живучести × conMult (Закалка) добавляется полностью в обоих режимах (как сегодня). Вариант «максимум кости» не используется; для старых персонажей без записей поведение сохраняется прежнее.

## Данные

- `CALC.avgDie(d)` — новый хелпер: `Math.floor(d/2)+1`.
- `char.hpLevels = {}` — карта `уровень → кость, фактически полученная` (результат броска или среднее). Добавляется в `CALC.defaults()`.
- `CALC.maxHp`: цикл уровней 2..L: `total += hpLevels[l] != null ? hpLevels[l] : r.hitDie`, плюс `conMod * cm` за уровень. Отсутствие записи ⇒ hitDie (совместимость, регрессия чистая). Уровень 1 не затрагивается (база `4*hitDie + round(conMod*3.5)`).

## Модалка (src/app.js levelUpModal)

- Секция «Хиты»: две кнопки **«Кинуть dN»** и **«Среднее: +M»**.
- По умолчанию выбран режим **бросок**, но результат не проставлен — бросок только по нажатию «Кинуть dN» (повторные нажатия = переброс).
- Превью: режим бросок без результата → «кость не брошена»; после броска → `+N (кость N + мод M)`; режим среднее → `+M (среднее dN + мод M)`.
- «Применить» в режиме броска без результата: toast «Бросьте кость или возьмите среднее», модалка остаётся открытой.
- Floating: `levelUpState.hpMode = 'roll' | 'avg'`, `levelUpState.roll = число | null`.

## Применение (applyLevelUp)

- `char.hpLevels[newLevel] = roll | avgDie(hitDie)`.
- `char.hp.max = CALC.maxHp(char, DATA)` — единственный источник истины; дельта текущих хитов как сейчас.
- Поле `hpLevels` уходит в JSON экспорт/импорт в составе объекта персонажа.

## Тесты (TDD)

1. `test/calc.test.js`:
   - `avgDie` для 6/8/10/12.
   - `maxHp` с `hpLevels: {2: 5}` (d8, conMod 0) → уровень 2 = база + 5.
   - Смешанные уровни `{2: 5, 3: 8}` на d8.
   - Отсутствие записей → эквивалентно старой формуле (hitDie).
   - Уровень 1 с hpLevels не меняет базу.
2. Харнесс level-up (t16): модалка открывается в режиме «бросок» без результата; «Кинуть» (Math.random стаб) показывает результат; переключение на среднее меняет превью; apply пишет `hpLevels[newLevel]` и `hp.max` совпадает с превью; guard-тост без броска.
