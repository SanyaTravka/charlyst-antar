# Дизайн: Интерактивный чарлист для системы «Антар»

Дата: 2026-08-16
Статус: утверждён пользователем

## Цель

Интерактивный чарлист для НРИ-системы «Антар» (редакция 0.98, мод на D&D 5e): создание персонажа по правилам, редактирование листа, боевой трекер, сохранение в JSON. Приложение — один самодостаточный HTML-файл, работающий офлайн на любом устройстве (браузер, `file://`).

## Требования

- Один HTML-файл `antar-sheet.html` со встроенными CSS и JS, без внешних зависимостей и сборки
- Русский интерфейс, пергаментный/ретро стиль
- Полная автоматизация: каталоги правил 0.98 зашиты в файл, авто-расчёт модификаторов, хитов, маны, запаса сил, КД, скорости
- Пошаговый мастер создания персонажа
- Лист персонажа с вкладками
- Полный боевой трекер (хиты/мана/запас сил, состояния, травмы, истощение, спасброски смерти)
- Сохранение: localStorage (автосохранение) + экспорт/импорт JSON-файла
- Незаконченные в правилах 0.98 разделы (специализации Воинское искусство, Призыв, Очарование, Проклятия, Воинская магия) — пустые деревья с ручным добавлением способностей

## Архитектура

Один файл `antar-sheet.html` (vanilla JS, без фреймворков и сборки):

- `<head>` — CSS (пергаментная тема), meta viewport для мобильных
- `<body>` — шапка (переключатель чарников, экспорт/импорт, создать), экран выбора, экран мастера, экран листа, модальные окна, тосты
- `<script>` — три логических блока:
  - `DATA` — каталоги правил (данные)
  - `STORE` — localStorage: ключ `antar.characters`, автосохранение, экспорт/импорт JSON с валидацией
  - `APP` — состояние, рендер (`render*()` функции), обработчики событий (делегирование)

Единственный источник истины — объект `state` (массив чарников + текущий выбранный id). Любое изменение: мутация `state` → `STORE.save(state)` → `APP.render()`.

Вёрстка рендерится из JS-состояния (innerHTML-шаблоны), без ручного DOM-связывания.

## Каталоги данных (DATA)

Вручную вводятся из правил 0.98:

| Каталог | Содержимое |
|---|---|
| `races` | 9 рас: бонусы к характеристикам, кость хитов, размер, особенности (напр. гномы: ограничения) |
| `statuses` | 12 соц. статусов: навыки/ремесла/знания, бонусы к характеристикам, +ЗС/+мана, имущество (справочно) |
| `traits` | 20 постоянных черт (бросок d20) с текстом |
| `skills` / `lores` / `crafts` | 25 навыков / 19 знаний / 17 ремёсел: привязанные характеристики |
| `specializations` | 14 специализаций (телесные: 1 ОС/перк, приобретённые: 1 ОС/2 перка); 9 с готовыми деревьями способностей, 5 пустых |
| `abilities` | Способности: специализация, тир 1–4, пассивная/активная, затраты (мана/запас сил), длительность, дистанция, текст |
| `weapons` | ~20 видов оружия: тип, скорость (атак/ход), свойства (парирование и пр.), досягаемость, урон, ручное оружие |
| `armor` | 5 уровней доспехов (КД 14/16/18/20/22, штрафы) + 3 щита (+1/+2/+3) |
| `conditions` | 17 состояний (текст для справочника) |
| `injuries` | 4 зоны травм |
| `exhaustion` | 6 степеней истощения |
| `osByLevel` | Таблица ОС за уровни: 1:3, 2:2, 3:2, 4:2, 5:3, 6:3, 7:2, 8:2, 9:2, 10:3 (далее «ждём редакций») |

Каталоги — чистые данные; формулы и правила авто-расчёта — в блоке APP (функция `calc`).

## Модель чарника

```js
Character = {
  version: 1,
  id: string, name: string, raceId: string, statusId: string,
  traitId: string|null, traitRolled: bool,
  level: number,
  attrs: {сила, ловкость, живучесть, воля, восприятие, харизма, мудрость, интеллект},  // значения 3..20
  hp: {current, max, bonus}, stamina: {current, max, bonus}, mana: {current, max, bonus},
  trained: { skills: {id: 'normal'|'expert'}, lores: {...}, crafts: {...} },
  specializations: [id],           // выбранные 4 (или 5 с чертой «Гений»)
  abilities: [id],                 // купленные способности из каталога
  customAbilities: [...],          // ручные способности (для пустых деревьев)
  weapons: [WeaponEntry],          // WeaponEntry: {id?, name, custom?, type, speed, props, reach, damage}
  armor: {kindId?, custom?}, shield: {kindId?, custom?},
  inventory: [string],             // строки-предметы
  conditions: [id],                // активные состояния
  injuries: {head, arms, torso, legs},  // булевы
  exhaustion: 0..6,
  deathSaves: {success, fail},
  spentOS: number,                 // потраченные ОС
  osBonuses: {stamina, mana, hp},  // купленные за ОС бонусы
  notes: string,
  createdAt: timestamp, updatedAt: timestamp
}
```

## Авто-расчёты (формулы из правил)

- Модификатор: `floor((attr - 10) / 2)` (как D&D)
- Хиты макс: `4 × кость_расы + мод.Живучести × d6` (нулевой уровень, детерминировано: `4×кость + round(мод.Живучести × 3.5)`) + по `кость_расы + мод.Живучести` за каждый уровень выше 0 + бонусы ОС (1 ОС = 5 HP)
- Запас сил: `2 + 4 × мод.Живучести` + бонусы статуса (+3/+5/+10 и т.д.) + бонусы ОС
- Мана: `2 + 4 × мод.Воли` + бонусы (+8 учёный) + бонусы ОС
- Скорость: `4 + floor(мод.Ловкости / 2)` клеток
- КД: доспех (14/16/18/20/22) + щит (+1/+2/+3) + прочие бонусы (записываются руками)
- Инициатива: `d20 + актуальная скорость` (кнопка броска в трекере)
- ОС всего: `Σ osByLevel[1..level]` (+1 за каждый 3-й уровень при черте «Приспосабливаемый», на каждый 3-й уровень — «Тупой»: −1 за уровень)
- Броски: кнопки-дайсеры d20/d12/d10/d8/d6/d4 на листе (переброс одного кубика)
- Уровневый бонус (бонус мастерства): в правилах 0.98 формула не задана — редактируемое число на листе (по умолчанию 0), используется в быстрых бросках проверок

## Экраны

1. **Экран выбора** — карточки сохранённых чарников (имя, раса, уровень, специализации), кнопки «Создать», «Экспорт», «Импорт», удаление чарника
2. **Мастер создания** — 6 шагов:
   1. Раса (авто-бонусы характеристик)
   2. Соц. статус (показ бонусов, авто-навыки/ремесла)
   3. Бросок d20 черты (кнопка «Кинуть»; можно пропустить)
   4. Характеристики: раскидывание 27 очков, мин 8 / макс 18; раса/статус добавляют бонусы сверху
   5. Выбор 4 специализаций (5 при черте «Гений»)
   6. Стартовые способности за ОС 1 уровня (3 ОС) + распределение хитов (детерминированный расчёт)
   Итоговый предпросмотр → «Создать персонажа»
3. **Лист персонажа** — вкладки:
   - **Обзор**: имя/раса/статус/уровень, характеристики с модами, авто-значения (хиты, мана, запас сил, КД, скорость, инициатива), оружие, доспех/щит, инвентарь
   - **Специализации и способности**: деревья по специализациям и тирам, трата ОС, покупка способностей, ручное добавление для пустых деревьев
   - **Заклинания**: способности магических школ, сгруппированы по школам/тирам, фильтр по тексту
   - **Справочник**: состояния, травмы, истощение, черты, расы — поиск
   - **Заметки**: свободный текст
4. **Модалки**: выбор оружия/доспеха (каталог + ручной ввод), карточка способности (описание + «Взять»), список состояний (чекбоксы)

## Боевой трекер

Шапка листа (закреплена):
- Три шкалы: хиты / мана / запас сил — текущее значение, кнопки «−1», «−5», «+1», «Восстановить» (макс)
- Порог ⅓ хитов (правило: скорость и уклонение вдвое) — авто-подсветка шкалы
- 0 хитов → панель спасбросков смерти (2 провала = смерть)
- Счётчик истощения 0–6 (клик/скролл)
- 4 чекбокса травм (голова / верхн. конечности / торс / нижн. конечности)
- Чипсы активных состояний; клик — модалка с 17 состояниями (чекбоксы)
- Бросок инициативы: `d20 + скорость`, результат в тост
- Кнопка «Новый ход» — сброс счётчика динамичных защит и отметок

Справочные тексты состояний/травм/истощения доступны в модалке и на вкладке «Справочник».

## Поток данных

- `STORE.load()` при старте → `state`
- Каждое изменение: `mutate(fn)` → `STORE.save()` (try/catch) → `APP.render()`
- Экспорт: `Blob` (JSON, `version: 1`) → скачивание `<имя-чарника>.antar.json`
- Импорт: `<input type=file>` → `JSON.parse` → валидация (обязательные поля, version) → добавление в список
- Ошибка импорта → тост «Файл повреждён или это не чарник Антар»

## Обработка ошибок

- Импорт: try/catch вокруг `JSON.parse`, сообщение при несоответствии `version`
- `QuotaExceededError` / недоступный localStorage (приватный режим): тост «Не удалось сохранить — экспортируйте JSON»
- При загрузке чарника из JSON все поля деструктурируются с дефолтами — старый/битый JSON не ломает рендер
- Пустые каталоги (пустые специализации) не дают ошибок — рендерятся пустые деревья с кнопкой «Добавить способность»

## Тестирование

Ручной тест-лист (открытие `antar-sheet.html` в браузере):
1. Создание чарника каждой из 9 рас — авто-бонусы применены
2. Все 12 статусов — бонусы и владения применены
3. Черта d20 — ролл, учёт в ОС («Приспосабливаемый», «Тупой», «Гений»)
4. Раскидывание характеристик 27 очков — границы 8–18
5. Трата ОС на способности и бонусы (мана/запас сил/хиты)
6. Экспорт → импорт → идентичность данных
7. Редактирование, закрытие и повторное открытие файла — данные из localStorage
8. Удаление и переименование чарника
9. Мобильный viewport — вёрстка не ломается
10. Боевой трекер: шкалы, состояния, травмы, истощение, смерть (2 провала), инициатива
11. 0 ошибок в консоли браузера

## Критерии завершения

- Файл `antar-sheet.html` открывается двойным кликом с `file://` без ошибок консоли
- Все пункты тест-листа проходят
- Чарник сохраняется/загружается через localStorage и через JSON-файл
